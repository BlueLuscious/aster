dynamic loader maps. Artwork, identities and collection membership are unchanged.

- Breaking change: replace the collection export `AmellusCollection` with `Amellus`, without
  a compatibility alias.
- Breaking change: align `CollectionManifestEntry.symbol` with the new canonical export name.
- Compatible correction: prevent inherited Object properties from resolving as loaders while
  preserving valid own keys, frozen maps, deferred evaluation and native import failures.
- Compatible correction: consolidate individual-icon and collection README examples and link
  canonical guides and version history.

Requires Core `^0.1.1`. Apply the [export-naming migration](../collections/index.md#export-naming-migration);
the [loader guide](../dynamic/index.md#arbitrary-key-access) owns corrected lookup semantics.
