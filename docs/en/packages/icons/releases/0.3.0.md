# Aster Icons 0.3.0

Status: **Draft; not yet published**.

This version exposes explicit Outline definitions and a separate variants dictionary for each
glyph. The existing 26 glyphs and their geometry are retained; it adds no Filled, Dotted or
Stippled artwork.

- Breaking change: give existing definitions explicit identities such as `aster/camera@outline`
  and exports such as `CameraOutline`, available through `.../camera/outline`.
- Breaking change: make `.../camera` export only `CameraVariants`, not the previous `Camera`
  definition or individual treatment exports. The dictionary has no default and is not renderable.
- Breaking change: expose selected collection treatments through
  `Amellus.icons.camera.outline`; `Amellus.members` remains an ordered list of definitions.
- Breaking change: rename `symbol` to `exportName` in icon and collection manifest records, and
  require explicit treatments in icon manifest/loader keys.
- Compatible capability: provide frozen, prototype-free glyph dictionaries whose entries share
  the canonical definitions used by isolated imports, collections and dynamic loaders.
- Compatible correction: load selected canonical definitions directly while preserving deferred
  acquisition, absent-key behaviour and independent individual imports.

Requires Core `^0.2.0`.

## Migration

Replace `Camera` imported from `.../camera` with an explicit leaf import, or select a treatment
from the new dictionary:

```ts
import { CameraOutline } from "@luscious-garden/aster-icons/camera/outline";
import { CameraVariants } from "@luscious-garden/aster-icons/camera";
import { Amellus } from "@luscious-garden/aster-icons/collections/amellus";

const individual = CameraOutline;
const grouped = CameraVariants.outline;
const selected = Amellus.icons.camera.outline;
```

Import the individual subpath when only one treatment is needed; importing a dictionary evaluates
all its distributed treatments. Neither entry retains a compatibility `Camera` export.
The `Amellus` export and collection subpath are unchanged.

Update custom manifest consumers from `.symbol` to `.exportName`, and replace loader lookups such
as `AsterIconLoaders["aster/camera"]` with `AsterIconLoaders["aster/camera@outline"]`.
No alias or treatment fallback is provided. The [glyph guide](../glyphs/index.md) and
[collection guide](../collections/index.md) own current consumption; custom collection authoring
also needs the [Core migration](../../core/releases/0.2.0.md#migration).
