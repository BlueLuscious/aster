# Import Quality

Status: **Verified private boundary**

Verification exercises operation, adapter, distribution and independent-consumer contracts;
matching a public stable source version does not make Import public.
[Compatibility](compatibility.md) owns the private ABI and [workflow](workflow.md) owns execution.

## Conformance

| Evidence | Boundary verified |
| --- | --- |
| Public-operation runtime tests | Five independently composable operations, complete required fields, frozen results, mutation isolation and atomic batches. |
| Draft tests | Metric/provenance envelope checks, canonical geometry counts and separately supplied matching drafts. |
| Input-hardening tests | Accessors, symbols, hidden fields, custom prototypes, sparse/cyclic data and original caller-controlled Proxy failures. |
| SVG adapter tests | Supported geometry, editor-noise warnings, blocked semantics/resources, XML safety and structured path expansion. |
| Parser tests | Every exact resource ceiling and immediately greater value, namespace/inert-section rules and LF/CRLF/Unicode spans. |
| Diagnostic tests | Closed code/category/severity policy, canonical ordering, deduplication and immutable result unions. |
| ABI tests | Exact root values and declarations, rejected subpaths, contained dependencies and an isolated compiled emitted-module consumer. |
| Repository workflows | Equivalent TypeScript-first/adopted definitions and independent host-owned batches through Core, Import and SVG roots. |

Run `pnpm --dir packages/import run test`. [Project testing](../../project/testing.md) defines
cross-package verification. Output markers and accessibility attributes remain rejected by the
[SVG subset](formats/svg/index.md); conformance is not an export/reimport promise.

## Measured evidence

The [baseline](quality-baseline.md) retains workloads, environments, growth observations and cost
attribution. Inspection owns the material cost; measured definition construction and editable
emission do not justify shortcuts. Timing is advisory, never a replacement for source safety,
precise diagnostics, isolation or deterministic output.

## Host limits

Import does not acquire bytes, detect encodings, discover files, infer metadata, enforce collection
visual policy or persist output. It owns no overwrite, generated cleanup, source scaffolding or
cross-collection transaction. [Adoption](adoption/index.md) defines the editable hand-off rather
than a regeneration lifecycle.
