# Aster Import 0.1.0-rc.2

Status: **Private source candidate; not published**.

Source-version commit:
[`756a8392c7384c3fdb0a2a403473ef337209b909`](https://github.com/BlueLuscious/aster/commit/756a8392c7384c3fdb0a2a403473ef337209b909)
(6 October 2026, UTC).

The second private candidate corrected supplied-draft consistency and external SVG lexical
acceptance without adding an operation or host capability.

- Validate supplied draft metrics, built-in format and logical provenance before Core construction.
- Compare primitive and path-command counts with canonical geometry, rejecting inconsistent
  evidence with field-specific `IconImportError` paths.
- Reuse the shared SVG whitespace grammar for numeric attributes and parser text; reject
  unsupported Unicode spacing with located diagnostics.
- Verify rejection of renderer-owned and unrelated `data-*` attributes rather than broadening
  the source subset.

Hosts supplying drafts directly must provide matching metrics and canonical provenance.
Valid source formatting remains limited to SVG whitespace, not arbitrary Unicode spaces.
[Adoption](../adoption/index.md#definition-construction) and
[SVG Shared](../formats/svg/shared/index.md) own the current rules. No public package, release tag
or archive accompanied this private source version.
