# Aster Import 0.1.0-rc.1

Status: **Private source candidate; not published**.

Source-version commit:
[`6c44b03c31335addc644a45c21d0ed49b8517b17`](https://github.com/BlueLuscious/aster/commit/6c44b03c31335addc644a45c21d0ed49b8517b17)
(22 September 2026, UTC).

The first formal candidate retained the host-independent adoption compiler under
`@luscious-garden/aster-import`, with `private: true`. It introduced no public registry channel.

- Retain the five staged and composed operations: inspection, reviewed definition, editable
  emission, single adoption and atomic batch adoption.
- Accept the strict SVG source subset through the confined XML parser and Aster-owned diagnostics.
- Emit ordinary human-owned TypeScript depending only on Core, without host or generation effects.

Earlier private manifests had already used `0.1.0` and the former `@aster/import` name; those
internal labels were not public stable releases. This record identifies the formal candidate
boundary, not the compiler's first implementation. Current behaviour is owned by the
[API](../api/index.md); subsequent draft and lexical corrections are recorded in
[the second candidate](0.1.0-rc.2.md).
