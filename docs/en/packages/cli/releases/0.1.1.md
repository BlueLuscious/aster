# Aster CLI 0.1.1

Status: **Draft; not yet published**.

This patch prepares clearer installation guidance and the updated built-in Icons catalogue
without adding commands or changing public command contracts.

- Compatible correction: use Icons `^0.2.0` for the built-in catalogue while preserving
  identity-based discovery and collection loading.
- Compatible correction: consolidate CLI usage and link the shell guide for invocation,
  local versus executed-CLI version sources and failure behaviour.

Also requires Core `^0.1.1` and SVG `^0.1.1`. No CLI grammar migration is required from `0.1.0`.
Consumers importing collections directly must apply the
[Icons export-naming migration](../../icons/collections/index.md#export-naming-migration);
the [shell guide](../shell/index.md) owns invocation and version-query semantics.
