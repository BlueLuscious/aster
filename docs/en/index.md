# Aster Documentation

Aster is an independent icon platform for creating, describing, validating, distributing, and
rendering curated icon collections.

Canonical documentation is written in English and organized by responsibility:

- [Architecture](architecture/index.md) defines project-wide guarantees and boundaries.
- `packages/` will document packages that exist in the repository.
- `collections/` will document collections that exist in the repository.

Package and collection documentation is created only when its corresponding repository structure
exists.
