# First Candidate Publication

Status: **Verified historical publication on 22 September 2026**.

Source commit: `7c7efd67d8f6f60204cfa268e0ce4fcf4b794df1`.

The first public set comprised four independently versioned `0.1.0-rc.1` packages. A clean
frozen offline workspace installation, complete verification, pack inventories and isolated
tarball consumers passed on Node `24.10.0` with pnpm `10.28.1`.

Core had no production dependency. Every public runtime edge in the verified combination
resolved to `^0.1.0-rc.1`. These counts and ranges describe this candidate, not future contents.

The archives contained emitted ESM/declarations, manifests, READMEs and software licences;
Icons additionally carried its artwork licence. They excluded private Import, source trees,
tests, tooling and credentials. The [Icons rights boundary](../../packages/icons/index.md#rights-boundary)
owns the software/artwork distinction and legal-authority links.

Authenticated checks identified `blue_luscious` as owner of the `luscious-garden` npm organisation
at publication. After reviewing archive contents, rights, commands and hashes, the maintainer
gave an explicit go. Publication completed in dependency order. An external anonymous consumer
installed all four exact versions, ran CLI catalogue discovery and rendered an imported icon.

## Observed channels

Publication explicitly requested `next`, but npm also assigned `latest` to the first versions.
Attempting to remove Core's initial `latest` returned `400 Bad Request`. This records an observed
outcome, not a general registry guarantee. Exact versions identify this historical candidate;
the [stable publication](0.1.0.md) later replaced its `latest` pointers through new archives.

No candidate Git tag or GitHub pre-release was created.
