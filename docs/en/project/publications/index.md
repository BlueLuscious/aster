# Publication Records

Dated results for exact package combinations, newest first. Records own joint verification and
observed registry channels; linked package version notes own changes, migrations and archive
evidence. Publication records are not repository-wide versions or GitHub Releases.

Use the UTC npm publication date as the filename: `YYYY-MM-DD.md`. Separate publication records
on the same day use `YYYY-MM-DD-02.md`, `YYYY-MM-DD-03.md` and so on, without renaming the first
record.

not included. [Publication policy](../publication.md) owns procedure and approvals.
