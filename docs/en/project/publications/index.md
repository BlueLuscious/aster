# Publication Records

Dated evidence for reviewed npm package combinations, newest first. These records are not
repository-wide GitHub Releases: each public package keeps its own version and Release.

Records own approved combination-level verification and observed registry channels at the stated
time. They are not live `latest`/`next` queries or instructions to republish an existing identity.
Private Import participated in workspace verification but none of these publications included it.

Package histories own changes, migrations and archive evidence:
[Core](../../packages/core/releases/index.md), [Icons](../../packages/icons/releases/index.md),
[SVG](../../packages/svg/releases/index.md) and [CLI](../../packages/cli/releases/index.md).
The historical CLI rc.3 note delegates its archive hash to its publication record; other public
version pages retain their hashes directly.

[Publication](../publication.md) defines the repeatable procedure and approval gates;
[versioning](../versioning.md) defines compatibility and dependency coordination.
