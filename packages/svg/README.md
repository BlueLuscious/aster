# @aster/svg

Framework-independent SVG rendering contracts for portable Aster icon definitions.

The current foundation exposes the `SvgApi` contract and `SvgMarkupType`. Runtime rendering will
be added after the complete output boundary is verified.

See the [canonical package documentation](../../docs/en/packages/svg/index.md) for
responsibilities, exports, and rendering semantics.
