# @aster/import

Private host-independent services for adopting external icon sources as portable Aster
definitions and editable TypeScript modules.

The current boundary owns explicit format adapters, source diagnostics, safe SVG inspection,
portable draft construction, Core definition validation and adoption composition. It contains no
filesystem, command-line, source-discovery, overwrite or generated-file ownership authority.

See the [canonical package documentation](../../docs/en/packages/import/index.md).
